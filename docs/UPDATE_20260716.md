# VBT Update 2026-07-16

This snapshot extends the original scientific and smoke VBT project into a
unified compression, reconstruction, rendering, and validation workspace.

## Representation And Data

- Preserved the scientific, smoke, fire, Blender proxy, and native Cycles code.
- Integrated the former `3D` workspace into the main repository.
- Added liquid level-set support through the Mode2
  `TemporalGrid4 + TemporalShellVoxel` path with sign-aware surface protection.
- Added a categorized `data/` catalog for smoke, fire, and fluid runtime assets.
- Added aligned original/reconstruction workflows for smoke, fire, and fluid.

## VBT Studio

`VBTStudio/` is now part of this repository as an independently buildable
backend/frontend desktop project. It supports:

- direct dynamic VBTPACK4 playback without per-frame VDB conversion;
- density + flames + temperature field alignment;
- smoke/fire material presets and Physical Fire rendering;
- Fast Surface and Physical Water rendering for Mode2 level sets;
- camera, timeline, frame selection, PNG, PNG sequence, and MP4 controls;
- GPU timing and cache-memory inspection;
- visually checked nonblank smoke, fire, and fluid validation galleries.

Physical Fire adds ordered depth segments, Beer-Lambert extinction, smoke
scattering, HDR flames, optional temperature/blackbody emission, glow, and ACES
tone mapping. Physical Water adds supported `phi=0` crossings, entry/exit
thickness, IOR 1.333, absorption, reflection/refraction, studio lighting, floor
shadows, and selectable Y-up/Z-up presentation.

## Renderer Correctness

- Removed false granular level-set bounding boxes caused by accepting
  unbracketed near-zero SDF samples.
- Surface and shadow hits now require a sign crossing with negative-side
  support, while real droplets, sheets, and spray remain visible.
- Original/reconstructed metric pairs use aligned frame, camera, material,
  transfer function, and resolution contracts.
- Direct, fixed-cache, and compact-cache validation images are byte-identical.

## GPU Performance

The renderer now decodes temporal controls once per non-empty leaf and source
frame. A GPU-built active-leaf page table compacts the full-float cache without
changing VBTPACK4 files or adding sidecars.

| Contract | Direct | Compact cache | Speedup |
| --- | ---: | ---: | ---: |
| Industrial smoke | 15.157 ms | 3.051 ms | 4.967x |
| Ground Physical Fire | 75.321 ms | 7.506 ms | 10.035x |
| Aerial Physical Fire | 100.581 ms | 16.916 ms | 5.946x |
| Fluid performance | 67.172 ms | 7.865 ms | 8.541x |
| Fluid quality | 86.722 ms | 14.573 ms | 5.951x |

Aerial three-field cache memory decreases from 1,791.04 MiB to 590.32 MiB.
Frames 60-62 render at 47.87-52.67 FPS at 640 x 640, including cache rebuilds.

## Repository Policy

GitHub contains the core source code, tests, metadata, documentation, and a
small curated effect-image set. Generated build trees, `outputs/`, `.vbtp`,
RAW, VDB, Alembic, Blender files, videos, reports, paper workspaces, validation
galleries, and archives remain local because they are large or reproducible.
