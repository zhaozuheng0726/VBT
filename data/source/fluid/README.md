# Water-flow source provenance

The liquid experiments derive from the following third-party mesh animation:

- Title: `water flow`
- Author: `aboubakrvfx`
- CGTrader item: `2522986`
- Public product page: https://www.cgtrader.com/3d-models/food/miscellaneous/water-flow
- Account download page: https://www.cgtrader.com/items/2522986/download-page
- Published: 2020-07-21
- Product description: `150 frames alembic`
- License shown on the product page: `Royalty Free License (no AI)`
- Access checked: 2026-07-23

The local source files are `3D/data/fluid/source/water_flow.abc` and the
associated Blender scene. The reproducible VBT experiment exports and uses 144
consecutive frames; this 144-frame count, rather than the product-page count,
is used for all RAW-size and compression-ratio denominators.

The original Alembic and Blender files are third-party assets. They are kept
outside the public source distribution and must not be redistributed through
the VBT repository. Only provenance metadata, conversion code, compressed
research outputs where permitted, and derived measurements belong in Git.
